# GitHub 项目清单

用于在成文前保留 GitHub 项目清单特有的事实与比较边界。本文件只准备材料，文件正文、栏目和说明不进入成文输入。

写作准备材料保留用户指定的项目数量、用途、格式，以及每个候选项目仍然成立的事实关系和必要上下文。用户要求排名、评测或锐评时，需要有材料能够支撑比较；只是资源合集时不制造排序。价格、维护状态、许可证、平台和技术栈只在用户要求或确实影响选择时加入。

入选和排序必须由当前材料支撑。不同项目可以用不同角度说明，只要读者能理解它们为什么被放在一起；不为视觉整齐把所有项目压进同一句型。

项目案例和钩子不参与普通成文，也不会成为本轮项目评价或实时事实。结构由同一份写作模板目录中的一个完整模板决定。

用户给出参考格式时沿用必要格式。准备完成后只把各项目原始事实、比较依据和必要上下文并入材料。草稿完成后核对实际写出的比较、实时字段和行动入口。
