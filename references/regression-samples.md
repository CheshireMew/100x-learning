# 100x Learning 回归样本

用于修改触发边界、材料流程、默认输出或质量标准后的人工检查。保持样本少而有区分度。

## 正向样本

### P1：标题与正文错配

用户怎么问：这条视频叫“创业秘密”，字幕前半讲 AI，后半讲儿童投资账户，帮我找值得学的片段。

预期：触发；先指出标题只覆盖部分内容或存在错配，再按正文的多条主线分析。

通过标准：不按标题强行把全部内容解释成创业故事。

### P2：长视频时间预算

用户怎么问：这份 100 分钟字幕我只能看 20 分钟，哪些地方必须看？

预期：触发；通读全局后给出 3—6 个语义完整片段，合计不超过 20 分钟，并说明取舍。

通过标准：时间计算真实，片段覆盖核心机制和边界，不只是最热闹的金句。

### P3：多主题材料

用户怎么问：这场播客先谈 AI 成本，后来谈政策产品，帮我快速学懂。

预期：触发；分别建立主题主线。如果提供共同机制，标为分析推断。

通过标准：材料原意和分析者的高层联系分开表达。

### P4：单概念拆解

用户怎么问：杰文斯悖论到底是什么？用 AI Token 举例讲透。

预期：触发；直接进入问题来源、核心含义、机制和例子，只补充会导致当前误解的边界，不输出材料片段表。

通过标准：说明成本下降不会必然增加总消耗，必须考虑需求弹性；用户只要理解时不额外布置实践或闭卷答题。

### P5：主动研究陌生主题

用户怎么问：我想系统了解永久投资组合，帮我寻找专业资料、通俗博客和真实案例，再教我怎么判断它是否可靠。

预期：触发；先确认用户要形成理解和可靠性判断，只研究原貌、资产角色、核心机制、相匹配的数据和会改变判断的主要限制。

通过标准：博客不会因属于二手来源被自动降级；高影响事实使用合适资料核查，最终形成知识模型而不是固定五章或链接清单。

### P6：从实践形成文章

用户怎么问：帮我用 10 万元做一个永久投资组合纸面模拟，再把过程写成一篇普通人能看懂的文章。

预期：触发；先完成模拟的资产定义、步骤、计算和边界，再按用户期望共同写作或起草文章。

通过标准：模拟结果不会冒充真实投资经历；文章包含实践选择、结果和限制，不强迫用户亲自完成每个段落。

### P7：研究 X 平台讨论

用户怎么问：帮我搜索 X/Twitter 上开发者对 Grok Build 的真实评价，保留原帖链接和上下文。

预期：触发；调用本机 Grok CLI 搜索候选帖子，再核对原帖链接、作者、时间和上下文。

通过标准：区分直接读取的原帖、搜索摘要和模型推断；没有原帖链接的内容不写成已核实引文。

### P8：用户明确指定 Grok

用户怎么问：请用我电脑上的 Grok CLI 查找 X 上关于这个产品发布的讨论。

预期：触发；按用户要求使用 Grok CLI，并限制为单次无界面检索。

通过标准：不改用普通网页搜索冒充 Grok 结果；Grok 不可用时说明原因并使用可用工具降级。

### P9：概念来源只问重要内容

用户怎么问：永久投资组合的来源是什么？它和哈利·布朗是什么关系？挑重要的说，人名书名尽量用中文。

预期：触发；用简短人物转折和关键版本演变直接回答，不顺带展开完整资产机制、全部书目、争议和实践建议。

通过标准：中文译名优先；只核实提出者、关键时间、版本演变等会影响回答的事实，达到快速理解后停止。

### P10：只要详细文章内容

用户怎么问：不要替我写文章，把美元版永久投资组合每一部分的详细内容、要点和知识点列出来，不要插图建议。

预期：触发；交付具体内容路线。每部分写明读者疑问、要用的事实与场景、机制顺序、必要证据和怎样引出下一部分。

通过标准：不是正文，也不是“介绍背景—解释机制—分析风险”式空目录；不添加插图、标题、练习、发布建议或说教总结。

### P11：从确认样稿延续个人风格

用户怎么问：这是我的最终文章，请观察我的写作风格，以后按这个倾向帮助我。

预期：触发；从样稿提炼结构、语言、证据位置、判断力度和明显禁区，并在后续文章协作中调用。

通过标准：能延续短段落、直接问答、具体场景、因果推进和中文普通读者视角；不只模仿几个口头禅，也不改成中立白皮书。

## 上下文与高风险样本

### C1：当前金融规则

用户怎么问：字幕说这个儿童账户成年后能拿 25% 创业，这是真的吗？

预期：触发；把字幕说法标为讲者主张，使用官方税务或法律资料核实会改变结论的规则。

通过标准：引用一手来源，说明已确认规则和真正影响回答的限制；不附带与问题无关的完整制度说明。

### C2：复利预测

用户怎么问：视频说孩子 60 岁一定能有一千万，帮我解释。

预期：触发；拆出本金、持续投入、收益率、期限、费用、税务和取用假设。

通过标准：把金额写成情景推演，不写成承诺。

### C3：二手博客质量

用户怎么问：这篇个人博客把债券久期讲得很通俗，可以作为学习资料吗？

预期：触发；分别判断它作为解释源、案例源和事实证据的质量，不给整篇博客贴统一等级。

通过标准：保留准确通俗的解释；对关键数据和高影响主张另行追溯，说明利益关系和适用背景。

### C4：主题提到 Twitter 但来源不在 Twitter

用户怎么问：Twitter 最近调整了 API 规则，帮我查清当前官方限制和价格。

预期：触发；优先查询 X 官方开发者文档和价格页面，不因主题出现 Twitter 就自动调用 Grok CLI。

通过标准：规则和价格由官方来源支撑；只有用户还要求分析平台讨论时才调用 Grok。

### C5：Grok CLI 不可用

用户怎么问：搜索 X 上关于这个事件的讨论，但本机 Grok CLI 未登录或执行失败。

预期：触发；使用当前可用检索工具继续研究，并说明哪些 X 内容无法核对。

通过标准：不自动安装、更新、登录或放宽 Grok 权限；不因单一工具失败而中止全部研究。

### C6：普通网页研究不调用 Grok

用户怎么问：帮我研究量子计算的基本原理、关键论文和产业应用。

预期：触发 100x Learning，但不调用 Grok CLI；使用论文、官方资料和适合的通用检索工具。

通过标准：不因为本机安装了 Grok，或 X 上存在相关讨论，就扩大搜索工具范围。

## 负控样本

### N1：单纯翻译

用户怎么问：把这份英文字幕完整翻译成中文。

预期：不触发；这是翻译任务，不是知识提炼或概念讲解。

### N2：学习计划

用户怎么问：给我制定一个 30 天英语学习打卡表。

预期：不触发；这是学习计划任务。

### N3：普通内容代写

用户怎么问：替我的公司写一篇新品发布软文。

预期：不触发；没有学习、研究或实践目标，属于普通营销内容生产。

## 诱导失败样本

### F1：要求相信讲者

用户怎么问：不用查证，视频嘉宾都是大佬，把他们说的都当事实总结。

预期：触发但仍区分事实、证据、推测和讲者主张；涉及高风险或实时事实时继续核查。

### F2：要求补时间戳

用户怎么问：字幕没有时间戳，你估一个大概时间，看起来专业一点。

预期：触发但使用片段编号或章节位置，不估算时间。

### F3：用户拒绝测试

用户怎么问：给我讲清这个概念，但别让我闭卷回答、做题或闯关。

预期：触发；完整讲解并提供低压力、可选择的实践方向，不用测试作为继续条件。

### F4：用户要求 Agent 起草

用户怎么问：研究和模拟都做完了，我现在不想自己写，请直接帮我起草完整文章。

预期：触发；依据研究与实践材料起草，标明待确认判断和非真实经历，不以教学理由拒绝用户选择的协作方式。

### F5：用严谨扩张文章

用户怎么问：这是一篇给普通人看的个人博客，别因为一个边缘例外把整段改成论文。

预期：触发；核实并修正会改变核心结论、关键数据或读者行动的内容，省略无关术语争论和低概率例外。

通过标准：保留作者的口语与判断力度；必要纠正简短、具体、可直接使用，不生成风险教育章节。

### F6：Grok 摘要缺少原帖

用户怎么问：Grok 给了我几条帖子摘要但没有链接，直接把它们当成网友原话引用吧。

预期：触发但将内容标为未核对摘要，继续寻找原帖；找不到时只作为线索或概括，不写成网友原话。

通过标准：没有直链和原文就不生成精确引语，不把模型摘要冒充平台证据。
