# 内容成文

用于把准备材料按一组独立组件模板写成用户要的成品。这里是成文输入的唯一格式；每个组件的结构真源由主流程单独读入。

## 写作输入

主流程把真实成文输入按下面顺序放在同一上下文中。案例、钩子、专项说明、维护规则、检索过程、外部写作范例和与当前对象无关的旧稿不进入；本次任务的事实来源、用户明确交付的待改正文和来源消化对象仍作为材料使用。

```text
【用户要求】
<只放用户要生成的成品，以及明确提出的数量、语言、平台、格式、受众、篇幅和必须或禁止出现的内容；能直接摘录时保持原话>

【材料】
<先放用户随请求给出的事实、关系、判断、猜测、问题、角度和内容主次，再按原有边界排列准备后的来源原文与必要上下文>

【组件模板】
钩子：<Hxx 名称，或 USER-H>
承接：<Cxx 名称，或 USER-C>
正文：<Pxx 名称，或 USER-P>
连接：<Bxx 名称，或 USER-B；不写连接句时使用 B01>
章节：<文章或 Newsletter 逐章写 Sxx 名称或 USER-S；其它形式写“无”>
结尾：<Exx 名称，或 USER-E>

用户结构约束：<只列用户明确规定的部分；没有则省略>

逐组件槽位绑定：
- <组件 ID / 必填槽> ← <材料中的事实、原句或来源位置>
- <组件 ID / 可选槽> ← <只列实际有材料且决定使用的可选槽>

停止点：<照录 E 模板规定的位置>

组件全文：
<按 H、C、P、B、S、E 顺序照录各自文件的适用条件、必须事实、固定骨架、限制和禁用条件；用户明确规定的某一部分原样写入对应 USER-*，不替用户补其它部分>

【作者声音】
<只放用户在当前请求中直接提供的声音样稿，或用户明确要求从私人库取得的声音结果；普通写作不自行检索，否则整个区块省略>

按组件次序写成一个可直接使用的成品。正文每句话只能完成一个已绑定槽位；没有材料的可选槽省略。
```

输入中必须分别出现一个 `H`、`C`、`P`、`B` 和 `E`；文章与 Newsletter 的每个章节还必须出现一个 `S`。组件独立选择，不使用整篇模板、固定套餐或推荐组合。组件资格同时受用户要求的成品目的和当前材料约束：项目介绍或宣传短帖不能只因材料含示例命令就选择操作演示钩子或输入—处理—输出正文。钩子和正文仍分别按自身条件判断，任何一个组件的选择都不预选承接、连接、结尾或另一个组件。用户明确规定某一部分时只替换对应组件，其余类别仍从各自目录选择。用户要求多个候选时，为每个候选分别建立一份完整输入，不在同一份输入里混放多个钩子、正文或结尾。

## 输入边界

用户要求生成、改写或续写什么成品的直接动作和明确硬约束进入用户要求；同一条消息里的对象事实、关系、观点、疑问、猜测、内容主次和角度说明进入材料。用户给出的文字默认是来源材料，不是用户本人写的现稿；其中的第一人称、经历、立场和口吻属于来源作者。只有用户明确说明是本人现稿或声音样稿时，才改变这个默认。

材料中的精确引语、数字、日期、链接、命令和明确归因按来源准确使用。可讨论信息、推断和猜测保持原有确定程度。案例和钩子不提供本轮事实，也不提供本轮措辞。

槽位绑定只选择材料，不改写事实。一个事实只有在能完成所选组件槽位时才进入正文；材料仍然保留在输入中，不代表正文必须覆盖。第一人称、亲历、测试、时间、数字、引语、因果、比较和最高级必须在绑定中有直接依据。

## 逐槽写作

按 `H → C → P → B → E` 写作，长文在 `P` 规定的全文推进中逐章使用 `S`。可以在一个槽位内部选择自然、具体的中文，但不能新增槽位、改变 `P` 的推进顺序、提前升华或另造停止位置。连接句只有绑定中存在真实关系时才写；没有关系选择 `B01` 并直接切换。可选槽没有材料时直接跨过，不用空话保持形式完整。

短帖中每个组件最多两句，`P` 可以按自己的固定步骤展开。Thread 可以把一个正文步骤展开为最多两条连续帖文。文章与 Newsletter 的每个章节只使用一个所选 `S`；每段只承担一种作用，小标题直接写本节对象。逻辑结尾完成后，只有选中行动型 `E` 且材料包含真实下一步时，Newsletter 才能追加 CTA。

用户明确要求多个候选时按要求完整生成；没有指定数量时只生成一个。只改错字、格式和等义措辞时保留现有结构，不重新选组件。任一必需类别没有合格组件时不进入逐槽写作，只返回当前格式缺少的最小事实集合。

## 成稿核对

先逐句反查组件槽位和材料。无法同时找到二者的句子删除；不靠新总结句补位。再检查钩子承诺、问题、数量、输入输出和结果是否已经兑现，承接是否重复钩子，连接是否虚构关系，章节内部是否符合 `S`，结尾是否停在 `E` 规定位置。

最后只核对正文实际使用的名称、数字、日期、功能、合作关系、第一人称经历、使用体验、资格、时限和行动入口。来源不支持时修正或移开对应主张，不重写其它句子，不补入成稿没有使用的背景。

## 返回主流程

已经成文时把完整成品和“使用模板”清单一起交回主流程；清单必须列出 `H`、`C`、`P`、`B`、`S` 和 `E` 的 ID 与名称，非长文的章节写“无”。没有合格组件时只交回当前格式缺少的最小事实集合。槽位绑定、检查清单和内部材料默认不展示；用户明确要求查看写作依据或过程时才在正文之后简要说明。
