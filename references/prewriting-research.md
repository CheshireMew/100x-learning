# 写作前材料发现与准备

这个阶段只负责为新稿找到参考材料没有提供、但能增加创作可能性的真实内容，并从完整来源中保留会让内容成立的事实、关系、细节和上下文。用户已经给出的数据、结论、活动规则和卖点直接作为当前材料，不在这里重新确认。参考材料是发现新内容的起点，不是待润色正文；除非用户明确要求忠实转述，它原有的观点、段落顺序和表达方式都不约束新稿。每个来源中保留下来的原始事实、必要术语、具体说法和上下文继续保持准确，专业词的解释、内容中心、开头、结构和结尾由成文阶段决定。

本文件只服务主流程已经判定的发现式新写。用户要求研究或核实、给定材料缺少让成品成立的关键事实，或者成品本身确实需要外部场景与比较时，才通过网络搜索补齐这个具体缺口。用户要求短内容且给定材料已经足以完成中心时，不进入本文件，也不为增加“洞察”“现实意义”或“传播力”搜索外部旁证。普通写作的事实核对等草稿产生后由成稿复查处理，不在本阶段提前发生。

## 发现有用材料

从用户原始要求和现有材料中找出一个确实会让成品无法成立的内容缺口，再围绕这个缺口搜索。可以补充真实场景、使用结果、人物反应、机制、因果关系、演示、比较、实际步骤、证据和自然说法；具体找什么由用户要的成品和材料缺了什么共同决定，不先把成品归入固定宣传模板。

每个候选来源都先回答一个问题：它给当前材料增加了哪个具体事实、场景、关系、结果或说法？没有答案的候选不进入写作材料；会把用户要的成品改成另一种任务的内容也留在原来源。账户、加成和计算方式已经由用户材料提供时，不再围绕这些字段建立搜索问题。金融活动的写作搜索不承担是否持有、卖出、开仓或配置资金的判断。

先打开用户给出的对象、页面或材料，确认没有认错主题并看见主要内容，同时认清现有材料已经说了什么、还没有解释什么。把没有解释的场景、原因、使用方式、比较、反应或现实意义作为搜索问题；一个查询如果只能再次得到材料中已有的数字、日期、条件或结论，就在发出前改成真正缺失的问题。随后浏览官网、仓库、文档、演示、媒体、创作者、真实用户、Issue、Discussion、论坛和社区讨论，寻找能够增加以下任一内容的原文与上下文：

- 具体动作、结果、演示、前后变化和使用瞬间；
- 人们如何描述问题、收益、比较、替代选择和意外反应；
- 比官方定位更自然、更容易被读者理解或转述的说法；
- 会改变选材、叙述视角或读者关系的案例和必要解释。

GitHub 项目可以组合项目名与 `demo`、`review`、`use case`、`tried`、`alternative`、体验、实测、对比、Issue、Discussion，以及 Reddit、Hacker News、X、YouTube、Bilibili 等来源词。搜索结果只用于发现入口，实际采用前打开原文或完整上下文。新来源不再增加场景、细节、比较或说法时停止，不按固定数量凑资料。每份进入写作材料的外部内容都保留原文链接，供成稿使用和固定的信息来源列表展示。

如果搜索结果只是在重复或确认用户已经提供的数据、卖点和结论，材料发现还没有完成，也不能把这些结果作为本次补充信息。改变查询方向，继续寻找对象怎样进入真实场景、为什么会产生当前结果、与替代方案有什么差异、人们怎样使用或评价，以及这些内容对目标读者意味着什么。新的查询不再增加创作可能性时停止，不能用核对已有事实填补“没有找到补充材料”的空缺。

只有当前成品确实需要行动入口、安装步骤、报名时间、价格、兼容性或提示词时，才额外寻找对应信息。它们不是普通介绍的默认材料。

## 准备材料

搜索得到的是候选，不是必须全部进入写作材料。保留真正可能影响本篇内容或写法的动作、结果、场景、机制、演示、比较、反应、原话，以及来源已经提供的必要解释；剔除与当前成品无关的部分。每个来源内部继续保持让事实成立的原始关系、准确措辞和必要上下文，不把多份来源压成会替写作者预设唯一观点的简报。用户要求逐字保留的内容直接保留；只要求提到或带到的内容保留完成该作用所需的部分，不连同无关段落一起放大。

进入创作上下文的内容应当帮助读者更快认识对象、理解变化、看见结果或完成下一步。下列内容没有增加这些作用时留在来源页：

- 官方套话、完整功能表、路线图和重复说明；
- 与用户要求和成品成立无关的背景与重复说明；
- 边缘功能、内部实现、无关适用条件和只供备查的技术字段；
- 搜索过程、来源等级、排除理由、候选评分和事实核查清单。

外部资料中的治理过程、许可证判断和技术验证，只有用户要的成品本来就需要这些内容时才进入写作材料。介绍机会、推荐对象或发布活动时，可以保留能增加参与场景、主要利益、采用结果和自然说法的内容；其它发现留在相应来源中。

价格、许可证、平台、兼容性、API Key、硬件、版本和运行条件不是一律删除，也不是一律保留：用户正在评估它们，或者缺少它们会让当前成品的主要行动失真时才进入写作材料。相应来源链接与材料保持对应，并在固定的信息来源列表中展示。

字幕、访谈和会议记录先恢复谁在回应什么、前后说法如何变化以及出现了什么结果，再提取相关片段；不要把时间切片顺序当成正文结构。

## 保留来源中的完整关系

完成取舍后，沿来源中的真实关系保留材料。一个事实依靠前后步骤、参与者、条件、原因或结果才能成立时，把这段关系完整留下；一句原话、一个数字、一次演示或一个使用瞬间承担吸引力和可信度时，连同理解它所需的上下文一起保留。来源只有一般机制或规则时就保留一般机制或规则，不为增强画面感补造人物、项目经历或使用场景。参考材料中的完整成稿仍然只提供其中成立的事实、关系、要求和创作线索，不因为它写得完整就成为新稿的结构模板。

材料中的专业词、内部说法、精确数字和适用条件按来源保留。材料准备阶段只整理来源内容，不提前替成品补写评价、背景或材料说明。各来源保持分开；来源链接不混入材料正文，但始终与对应材料一起交给主流程，供成稿使用和固定的信息来源列表展示。

## 写作使用的任务与材料

最终只保留以下内容供写作使用：

- 用户原始要求、用户明示的内容重点和必须保留的内容；
- 取舍后仍按来源保留的必要术语、完整事实关系、具体细节和上下文；
- 当前成品确实需要的行动、利益、时间或技术信息。

不同来源依次分开呈现，不把它们合并成新的说明文字。来源链接不与创作材料正文混写，但作为对应材料的来源记录交给主流程。专项模板、完整案例、独立钩子与按需取得的作者表达特点由主流程另行加入；外部对象材料不能代替私人库中的案例与钩子。材料中已经出现能够增加创作可能性的场景、机制、比较、反应或现实意义，或者继续搜索已经不再增加这些内容时停止；通俗表达、独立判断、传播力、开头、推进和结尾都由成文阶段完成。
