# 写作前材料发现与净化

这个阶段负责为写作找到足够真实、具体的材料，并从完整来源中剔除不适合当前成品的内容。材料净化只做删除：保留下来的内容继续使用来源原文、原有顺序、来源边界和必要上下文，不摘要、转述、重排、拼接或统一改写。专业词的解释、内容角度、主线、开头、结构和结尾都由成文阶段决定。用户已经给出的内容主次继续保持：重点可以影响哪些原文被保留，只要求提到或带到的信息只保留完成该作用所需的原文。

新写、扩写和实质重组默认进入，并通过网络搜索扩充创作材料。只改错字、格式或做等义压缩，或者用户明确只用给定材料时，不额外联网。用户要求研究、判断或事实核查时，另走研究路线；研究结果里真正适合公开表达的部分再进入本阶段。

## 发现有用材料

先打开用户给出的对象、页面或材料，确认没有认错主题并看见主要内容。随后浏览官网、仓库、文档、演示、媒体、创作者、真实用户、Issue、Discussion、论坛和社区讨论，寻找能够增加以下任一内容的原文与上下文：

- 具体动作、结果、演示、前后变化和使用瞬间；
- 人们如何描述问题、收益、比较、替代选择和意外反应；
- 比官方定位更自然、更容易被读者理解或转述的说法；
- 会改变选材、叙述视角或读者关系的争议、案例和必要解释。

GitHub 项目可以组合项目名与 `demo`、`review`、`use case`、`tried`、`alternative`、体验、实测、对比、Issue、Discussion，以及 Reddit、Hacker News、X、YouTube、Bilibili 等来源词。搜索结果只用于发现入口，实际采用前打开原文或完整上下文。新来源不再增加场景、细节、比较或说法时停止，不按固定数量凑资料。

只有当前成品确实需要行动入口、安装步骤、报名时间、价格、兼容性或提示词时，才额外寻找对应信息。它们不是普通介绍的默认材料。

## 净化材料

搜索得到的是候选，不是必须全部进入写作材料。净化只判断哪些内容应当剔除；其余内容保持来源中的原文、顺序和上下文，不把多份来源合并成摘要、写作简报或预先成形的观点。保留真正可能影响本篇内容或写法的动作、结果、场景、演示、比较、反应、原话，以及来源已经提供的必要解释。用户要求逐字保留的内容直接保留；只要求提到或带到的内容保留完成该作用所需的原文，不连同无关段落一起放大。

下列内容在与当前成品无关时留在来源页，不进入创作上下文：

- 官方套话、完整功能表、路线图和重复说明；
- 通用免责声明、保守提醒、风险罗列和为了显得全面而添加的背景；
- 边缘功能、内部实现、无关限制和只供备查的技术字段；
- 搜索过程、来源等级、排除理由、候选评分和事实核查清单。

研究、比较和核实阶段使用的治理过程、许可证判断、技术验证、反方材料与保守边界，只决定相关原文是否适合保留。用户没有要求展开，而且它们不会改变当前读者的理解或行动时，留在内部依据中；用户只要求带到结论时，保留来源中直接支撑该结论的原文和必要上下文。

价格、许可证、平台、兼容性、API Key、硬件、版本和运行条件不是一律删除，也不是一律保留：用户正在评估它们，或者缺少它们会让当前成品的主要行动失真时才进入写作材料。相应来源链接保留在任务内部，等草稿实际使用相关说法后再按需复查。

字幕、访谈和会议记录先恢复谁在回应什么、前后说法如何变化以及出现了什么结果，再提取相关片段；不要把时间切片顺序当成正文结构。

## 保留来源中的完整关系

完成净化后，沿来源中的真实关系保留材料。一个事实依靠前后步骤、参与者、条件、原因或结果才能成立时，把这段关系完整留下；一句原话、一个数字、一次演示或一个使用瞬间承担吸引力和可信度时，连同理解它所需的上下文一起保留。来源只有一般机制或规则时就保留一般机制或规则，不为增强画面感补造人物、项目经历或使用场景。不要用概括替代原文，也不要把原文改造成另一套“麻烦、动作、变化”等摘要。

材料中的专业词、内部说法、精确数字、限制和原始语气按来源保留。材料净化阶段不为目标读者补解释，不改写选中的内容，也不另写事实边界、风险提醒或材料不足说明。各来源保持分开；来源链接和核查依据留在任务内部，保留的原文及其必要上下文进入写作材料，供成稿实际采用后复查。

## 写作使用的任务与材料

最终只保留以下内容供写作使用：

- 用户要求、已经确定的内容主次和必须保留的内容；
- 净化后仍按来源原样保留的必要术语、完整事实关系、具体细节和上下文；
- 当前成品确实需要的行动、利益、时间或技术信息。

不同来源依次分开呈现，不把它们合并成新的说明文字。来源链接和核查依据继续留在任务内部，不与创作材料混在一起。专项模板、完整案例、独立钩子与按需取得的作者表达特点由主流程另行加入。材料净化到不适合的内容已经剔除、其余原文已经保留时停止；通俗表达、传播力、内容中心、开头、推进和结尾都由成文阶段完成。
