# 写作前联网研究与选材

用于实际起草新内容、扩写或实质重组之前，从网络上取得能够改善选题、传播力和具体表达的真实材料。上层已经选定写作动作、精确成品形态、表达任务和平台合同；本文件只决定为这次内容搜索什么、采用什么，并把精选材料交给后续作者思考与成文阶段。

## 进入与停止

新写、扩写或会改变主张与选材的改写默认进入。只做错字、标点、格式、等义压缩，或者用户明确要求只使用给定材料时，使用现有材料完成同样的筛选，不额外联网。

进入时上层提供：

- 写作动作、精确成品形态和已经选定的表达任务；
- 对象、目标读者、平台、长度和当前写作目标；
- 用户材料、当前有效正文、明确立场和必须保留的表达；
- 已知的事实入口，以及哪些内容属于作者本人经历；
- 用户已经使用的项目类别、任务名称、受众叫法和其它不能擅自改写的对象说明。

本阶段得到足以支持一个有吸引力的入口和正文推进的精选材料后停止。研究过程、未采用候选和来源中的其它信息不交给正文。

## 根据表达任务决定搜索什么

精确成品形态和平台合同决定篇幅与可用空间；表达任务决定网络研究真正要寻找的信息。只执行上层选中的一行：

| 表达任务 | 优先寻找 | 交给正文的材料 |
| --- | --- | --- |
| 正面介绍或推荐 | 真实称赞、持续使用原因、替换旧选择后的变化、前后对比、意外结果、具体用法、能够复述的数字或原话 | 最有传播力的正面变化、具体结果、使用场景、社会证明、必要的官方事实和真实入口 |
| 评测、比较或锐评 | 同一任务和标准下的实际差异、各自强项与弱项、成功和失败场景、适用对象、替代选择 | 能够支撑判断的对照事实、取舍、适用对象和结论 |
| 解释、教程或方法 | 普通读者的真实问题、成功完成的步骤、输入与输出、具体示例、可观察结果、会阻断完成的常见卡点 | 帮助读者看懂或做成的机制、例子、步骤和结果 |
| 观点、经历或回应 | 与作者主张直接相关的事件、案例、数据、常见说法和现实语境 | 能够加强作者真实判断的事实与案例；第一人称经历仍只来自用户 |
| 清单、资源选择或排名 | 统一选择标准、候选之间真正不同的角色、实际结果、适用对象、当前入口和会改变选择的实时字段 | 入选依据、排序依据、每项最有用的差异和入口 |
| 新闻、发布或近期变化 | 发生了什么、此前怎样、何时变化、影响谁、最早出现的真实反应和为什么现在值得关注 | 变化本身、时间、影响、具体反应和当前入口 |

用户在写作合同中明确要求正文出现的内容，按该要求进入材料包。除此之外，只把上表中已选表达任务会实际消费的材料交给正文；用于确认对象、核验真伪或比较候选但没有入选的事实留在研究阶段。

用户已经明确角度时，研究围绕这个角度找更强材料；研究结果帮助把它写具体，不另换成研究者更想写的主题。

## 搜索顺序

1. 先从用户材料和当前有效正文确定作者立场、已有事实和不能被网络材料替代的本人经历。
2. 使用官方网站、仓库、文档或原始发布确认对象叫什么、来源怎样说明它是什么、它直接做什么、作用于什么、真实入口和正文真正需要的精确信息。项目类别、主要用途和直接作用对象作为对象事实保存，不能在后续为了钩子而换成另一种项目用途。
3. 继续搜索真实使用讨论、独立体验、案例、演示结果、对比和受众原话，直到能够看出什么变化真正会被称赞、复述、采用或争论。把人们实际使用的任务名称和人群叫法原样记录；没有稳定说法时，使用“谁用它做什么”的具体动作，不创造宽泛的上位名称。
4. 根据已选表达任务筛选候选。来源只是重复官方功能、泛泛夸奖、与目标读者无关，或不能形成具体场景、动作、结果和判断时，不进入精选材料。
5. 选择一个最适合承担开头的传播点，再选择当前篇幅真正能够推进它的事实、案例、数字、原话或解释。另行列出材料已经具备的内容关系，例如明确痛点、前后变化、同一标准下的对照、真实误解与修正、规模、意外结果或具体代价。没有进入这份列表的关系，后续钩子检索和成文不能补造。数量由材料决定。

正面介绍或推荐只向后续阶段交付正面结果和能够支撑它们的材料；其它候选停在研究阶段。评测、比较、批评或其它表达任务分别交付该任务真正消费的材料。

## 怎样选择真正有传播力的材料

优先选择能够同时完成多项作用的内容：

- 读者一眼能看见变化前后，而不是只看到功能名称；
- 有具体的人、动作、任务、结果、数字或原话；
- 能让目标读者产生好奇、兴奋、共鸣、意外或立即想试一试；
- 能解释为什么有人愿意切换、持续使用、推荐、收藏或转述；
- 和作者当前立场及目标读者真正有关；
- 后文能够继续兑现，不靠夸张开头单独成立。

官方材料负责确认项目原貌和精确信息，真实使用材料负责发现传播点、场景和人会怎么说。两者共同支持同一表达时，正文先写读者能感受到的变化，再用必要的官方事实把它落稳，不把 README 的栏目顺序搬进成品。

## 来源怎样进入自然语言

按三种方式消费精选材料：

1. **逐项对应**：直接引语、精确数字、日期、链接、命令和明确归因保持来源中的对象与取值。
2. **保留关系**：材料证明的是切换后的感受、变化前后、相对优势、使用行为或受众反应时，保留这项关系，再按当前作者、读者和内容节奏重新表达。
3. **作者表达**：标题、钩子、类比、对照和判断由当前写作的编辑职责决定。用户明确给出或确认时优先沿用；用户没有指定时，根据作者位置、目标读者和材料支持的叙事关系选择。作者可以强化已经存在的关系，不能为一句钩子增加材料没有的痛点、冲突、比较对象、误解或时间变化。

来源提供事实、关系和表达材料，不接管作者的叙事选择。对象的类别、主要用途、直接动作和作用对象属于事实含义，不是可以任意替换的表面名称。来源或真实用法已经支持一个使用场景、结果或后果时，作者可以用自然中文突出它；没有现成任务名称时直接写具体动作。正文需要明确写成“某人说”“某次测试使用了某工具”或加引号时，再逐项对应原始来源。

## 交给写作阶段的精选材料包

只返回后续写作会实际消费的内容：

```text
写作动作、精确成品形态与表达任务：
目标读者和作者已经确认的立场：
对象事实：名称；来源怎样说明它是什么；直接做什么；作用于什么；已核实的能力、结果和入口
受众实际说法：来源或用户使用的任务名称、人群叫法；没有现成说法时记录可直接写出的具体动作
材料已有的内容关系：逐项列出能够支持的痛点、规模、前后变化、对照、误解修正、意外、结果或代价，并注明对应材料
开头最值得使用的传播点：
正文可用材料：每项写明具体内容、承担的作用、来源和核对方式
作者已经确认的表达：
实际采用的来源：
```

材料包只包含实际采用的内容。筛选完成后，它就是后续正文的唯一事实输入。对象事实防止后续钩子或案例改变项目用途，内容关系列表决定哪些钩子能够成立，受众实际说法决定正文怎样自然称呼任务和读者。上层调查信息只列实际采用的来源，以及它们怎样改变了选材；后续写作接收整份材料包，再由作者思考阶段完成本次呈现选择。
