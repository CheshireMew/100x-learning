# 独立钩子库

用于用户明确要求时新增、更新和维护完整钩子原文。它不读取完整案例，也不从案例开头自动生成钩子；活动钩子既是独立钩子与承接组件的蒸馏语料，也可以由正式取例工具列为钩子的模仿候选。普通写作按当前角度判断是否显式读取其中一份完整原文；模仿时不把钩子中的人物、事实或承诺带入当前内容。

## 存储与索引

活动钩子位于 `<私人知识库>/20-Sources/Hook Library/Examples/<写作技巧>/`，所有成品共用一份索引：

```text
<私人知识库>/20-Sources/Hook Library/钩子索引.md
```

索引按利益先行、结果先行、变化先行、问题切入、冲突切入、场景切入和信息缺口等写作技巧组织，不按主题、行业、对象、内容类别或成品形式组织。每个文件只保存稳定 `hook_id` 以及用户指定的连续开头与紧接内容；同一钩子可以用于短内容、Thread 或文章，不保存适用形式字段。

## 创建和更新

只有用户明确要求保存或更新独立钩子时才写入。输入必须包含连续开头与紧接内容，案例文件路径不能代替输入。写入活动目录前连续阅读全文：开头应依靠具体事实、动作、冲突、结果、问题或真实情绪成立，并能自然接入后文；只宣布“很重要、变化很大、时代变了”的通用句不能进入。

残缺片段、翻译腔改写、通用宣传句、无法迁移的题材句，以及已经被真实成品证明会放大模板感、抽象判断或篇幅的钩子不进入活动目录。不能确认质量时保留为候选材料。活动钩子持续污染真实成品时移到活动目录之外的可回查归档并重建索引。

活动钩子发生新增、修改或归档时，如果用户本次同时要求更新模板，必须重新读完钩子及紧接内容，并在逐来源覆盖账本中让该 `hook_id` 只出现一次：指向它实际支持的 `H` 和 `C`，或写明拒绝原因。与完整案例语义重复时标为降权，不能重复增加证据权重。

```powershell
python scripts/hook_library.py add-hook --input "钩子原文.md" --title "钩子标题" --hook-id "stable-hook-id" --technique "结果先行"
python scripts/hook_library.py build-index
python scripts/hook_library.py validate
```

更新已有钩子时修改唯一文件并重建索引。普通写作不自行浏览钩子库；正式取例工具先返回当前钩子组件的候选标题，模型确认与当前角度相关后才读取一份完整例子，也可以不读取。

## 通过标准

- 钩子脚本、目录、数据类型和统一索引不区分短内容、Thread 或文章，也不读取案例库。
- 活动钩子保存连续原文与稳定寻址字段，不保存题材分类和筛选故事，也不绕过正式取例工具整批进入普通成文输入。
- 归档内容不会进入活动索引。
