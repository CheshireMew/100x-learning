# 独立钩子库

用于在写作前定位用户已经明确保存的钩子原文，也用于用户明确要求时新增或更新钩子。它不读取完整案例，也不从案例开头生成钩子。

## 运行边界

活动钩子位于：

```text
<私人知识库>/20-Sources/Hook Library/Examples/<写作技巧>/
```

短内容、Thread 和文章各有自己的活动索引，每份索引只显示明确适用于该成品形式的钩子，并按写作技巧分组：

```text
<私人知识库>/20-Sources/Hook Library/短内容钩子索引.md
<私人知识库>/20-Sources/Hook Library/Thread钩子索引.md
<私人知识库>/20-Sources/Hook Library/文章钩子索引.md
```

主题、行业、对象和原始内容类别不参与索引。索引条目和文件名只显示不带题材含义的稳定 `hook_id`；钩子标题与原文只在按技巧选定编号并打开文件后出现。每个钩子文件只包含：

- 稳定的 `hook_id`；
- 明确适用的成品形式；
- 用户指定的连续开头与紧接内容。

写作技巧使用稳定的表达动作，例如利益先行、结果先行、变化先行、问题切入、冲突切入、场景切入或信息缺口；不把活动、产品、政策、AI、金融等题材变成技巧。钩子文件内不写技巧解释、公式、效果、评分或筛选理由。

## 写作读取

写作时只打开当前成品形式的钩子索引，根据当前材料实际拥有的张力选择两种不同的开头技巧，各按稳定编号打开一份连续原文并阅读全文；这里选择的是进入动作和承接方式，不是当前对象的表面句式或中心结论。不能先看标题或文件名再挑相近题材；对象名、平台名、行业名和主题词不能用于钩子检索。用户明确要求跨形式参考时，才读取另一种成品形式的索引。

钩子帮助写作者看见第一句话怎样给出继续阅读的理由，并自然接入后文；它不提供当前作品的事实、立场、经历和结果，也不能被当成用户的长期声音。完整读入后，写作者可以吸收它的表达距离、口语程度、句子节奏和承接方式，用当前材料重新写，不复制表面句型和独有口头禅，也不把技巧名称写进成品。

活动索引本身就是已经确认可用的原文集合；不适合继续参与写作的旧材料留在可回查归档，不把筛选规则和淘汰理由带进运行时。索引不存在、校验失败或当前形式没有所需技巧的原文时，准确说明私人库缺少什么并停止成文；不改搜相近题材、另一种形式或完整案例的开头。

## 创建和更新

只有用户明确要求把一段独立材料保存为钩子时才进入写入。输入文件本身必须包含需要保存的连续开头与紧接内容；案例文件路径不能代替输入。活动钩子必须来自完整、具体、能自然接入后文的真人表达；残缺片段、翻译腔改写、通用宣传句和已经被实际成品证明会放大模板感的钩子移入可回查归档，不进入活动索引。这项维护判断不写进钩子原文，也不进入写作输入：

```powershell
python scripts/hook_library.py add-hook --input "钩子原文.md" --title "钩子标题" --hook-id "stable-hook-id" --format short --technique "结果先行"
python scripts/hook_library.py build-index
python scripts/hook_library.py validate
```

更新已有钩子时直接修改唯一钩子文件并重建索引。没有用户明确写入要求时，普通写作只读。

## 通过标准

- 钩子脚本、目录、数据类型和索引不读取案例库。
- 钩子原文真实存在，文档只记录原文、稳定 id 和适用成品形式，不保存来源。
- 三份索引分别服务短内容、Thread 与文章，并且只按写作技巧分组。
- 活动钩子只有连续原文和寻址字段；活动索引与文件名不暴露内容标题。
- 写作可以同时读取案例与钩子，但两边没有相互引用或自动身份转换。
