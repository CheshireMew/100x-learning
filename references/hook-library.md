# 独立钩子库

用于普通写作读取完整钩子原文，也用于用户明确要求时新增、更新和维护钩子。它不读取完整案例，也不从案例开头自动生成钩子。

## 存储与索引

活动钩子位于 `<私人知识库>/20-Sources/Hook Library/Examples/<写作技巧>/`，索引分别是：

```text
<私人知识库>/20-Sources/Hook Library/短内容钩子索引.md
<私人知识库>/20-Sources/Hook Library/Thread钩子索引.md
<私人知识库>/20-Sources/Hook Library/文章钩子索引.md
```

索引按利益先行、结果先行、变化先行、问题切入、冲突切入、场景切入和信息缺口等写作技巧组织，不按主题、行业、对象或内容类别组织。每个文件保存稳定 `hook_id`、适用成品形式，以及用户指定的连续开头与紧接内容。

## 普通写作读取

普通写作只尝试读取当前可用的完整原文，不运行 `validate`。短内容、Thread 和文章浏览适合当前成品的可用原文；模型自行决定打开哪些、读多少和怎样综合。配置、索引或钩子不可用时继续写作。

索引只帮助找到全文，不能代替全文。钩子帮助模型感受一句开头怎样建立继续阅读的理由并自然接入后文；它不提供当前作品的事实、立场、经历、结果或用户声音。模型可以吸收表达距离、口语程度、节奏和承接方式，但不复制表面句型与独有口头禅。

## 创建和更新

只有用户明确要求保存或更新独立钩子时才写入。输入必须包含连续开头与紧接内容，案例文件路径不能代替输入。写入活动目录前连续阅读全文：开头应依靠具体事实、动作、冲突、结果、问题或真实情绪成立，并能自然接入后文；只宣布“很重要、变化很大、时代变了”的通用句不能进入。

残缺片段、翻译腔改写、通用宣传句、无法迁移的题材句，以及已经被真实成品证明会放大模板感、抽象判断或篇幅的钩子不进入活动目录。不能确认质量时保留为候选材料。活动钩子持续污染真实成品时移到活动目录之外的可回查归档并重建索引。

```powershell
python scripts/hook_library.py add-hook --input "钩子原文.md" --title "钩子标题" --hook-id "stable-hook-id" --format short --technique "结果先行"
python scripts/hook_library.py build-index
python scripts/hook_library.py validate
```

更新已有钩子时修改唯一文件并重建索引。没有用户明确写入要求时，普通写作只读。

## 通过标准

- 钩子脚本、目录、数据类型和索引不读取案例库。
- 活动钩子保存连续原文与稳定寻址字段，不保存题材分类和筛选故事。
- 普通写作可以自由读取和综合多个完整钩子；维护检查不参与普通写作。
- 归档内容不会进入活动索引。
