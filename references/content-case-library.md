# 完整内容案例库

用于在写作前查找真实完整成品，也用于用户明确要求时保存或更新案例。它不管理钩子；钩子由独立的钩子库、脚本和索引维护。

## 案例的正式原文

完整案例只保存一条真实成品从第一句到最后一句的原文、可迁移的写作技巧，以及确实属于写作记忆的独立字段。短内容位于 `<私人知识库>/20-Sources/Social Posts/Content Cases/完整短内容/`，文章位于 `<私人知识库>/20-Sources/Articles/Content Cases/`；两个目录都直接保存案例文件，不再按项目、行业、主题或内容类别分目录。

短内容和文章各有自己的活动索引：

```text
<私人知识库>/20-Sources/Content Cases/短内容案例索引.md
<私人知识库>/20-Sources/Content Cases/文章案例索引.md
```

每份索引只按“利益先行、变化先行、因果推进、案例推进、步骤推进、行动收束”等写作技巧分组。条目只显示稳定 `case_id`，案例文件也使用这个不带题材含义的编号命名；标题只在选定技巧并打开完整原文后出现。短内容任务只打开短内容索引，文章或 Newsletter 只打开文章索引；用户明确要求跨形式参考时才读取另一份索引。案例不保存任务、题材、对象、行业、宣发角色或利益领取者等检索字段，也不保存任何钩子字段。

## 查找与读取

只在当前形式的索引中按写作技巧定位参考。根据当前材料和成品形式，选择能帮助观察起笔、推进、信息密度或收束的不同技巧；短内容和 Thread 读取三份完整短内容案例，文章和 Newsletter 读取两份完整文章案例。不能先看标题或文件名再挑相近题材；对象名、平台名、行业名和主题词不能用于案例检索。相同题材不表示写法相同，不同题材也不妨碍技巧迁移。

活动索引是已经确认可用于学习写法的案例集合，也是运行时唯一入口。不适合继续影响成文的旧案例留在可回查归档，筛选理由不进入写作上下文。未出现在相应形式索引中的文件不能进入成文；网络搜索得到的新闻、评测和文章属于当前对象材料，不会成为案例。索引不存在、校验失败、当前形式没有所需技巧的可读原文时，准确说明私人库缺少什么并停止成文，不改搜另一种形式或相近题材。

选定后阅读全文，把多份纯原文作为连续 few-shot 直接交给成文阶段，不先归纳技巧、指定模板或证明用途。案例可以影响信息取舍、表达距离、口语程度、句子节奏和停止位置，但不提供当前对象的事实、人物、身份、经历、立场和结果，也不把内部技巧标签写进成品。

## 创建和更新

只有用户明确要求保存或更新案例时才写入。保存时保留未经改写的全文，不附加来源；完整短内容使用 `short`，文章使用 `article`。技巧只能从脚本支持的稳定写法中选择，不创建一次性题材标签。活动案例必须是完整、具体、确实值得学习取舍和推进的真人成品；残缺文本、翻译腔改写、规格堆叠、通用宣传稿和已经被实际成品证明会放大模板感的案例移入可回查归档，不进入活动索引。这项维护判断不写进案例正文，也不进入写作输入。文章输入来自正式文章时仍创建独立案例副本：

```powershell
python scripts/content_case_library.py add-case --kind short --input "完整原文.md" --title "案例标题" --technique "结果先行" --technique "因果推进"
python scripts/content_case_library.py build-index
python scripts/content_case_library.py validate
```

案例需要同时进入写作记忆时，通过 `--writing-format`、`--writing-purpose`、`--writing-origin` 和 `--voice-eligible` 明确声音检索所需信息；这些字段不进入案例索引。更新已有资源时直接修改唯一案例文件并重建两份索引。

## 通过标准

- 案例脚本、目录和索引只认识完整短内容、完整文章和稳定写作技巧。
- 短内容索引不出现文章路径，文章索引不出现短内容路径。
- 完整案例只显示原文和必要机器字段，不保存题材、任务、对象、行业或来源；活动索引与文件名不暴露内容标题。
- 案例文件不存在钩子字段，也不能通过案例路径生成钩子。
- 写作可以同时读取多个完整案例与多个独立钩子，但管理和索引边界保持分开。
