# 实践导向学习

用于把已经获得的知识转化为模拟、案例、工具、方案、判断或现实行动。实践服务用户目标。

## 一、什么算实践

实践是使用知识产生可观察结果，包括：

- 用概念分析一个真实事件或案例。
- 建立纸面方案、情景模拟或回测。
- 比较多个选择并说明取舍。
- 制作以后能复用的表格、模型、代码或清单。
- 在安全环境执行一个流程并记录结果。
- 根据实践形成决策说明、教程、文章或复盘。

能够帮助观察、判断、设计或行动的知识进入主流程，其余标为背景并压缩。

## 二、用户拥有实践目标

- 用户已经指定产物时，围绕该产物推进。
- 用户只说想了解时，先完成讲解。只有实践能明显帮助当前理解时，才简短提供一个可选方向。
- 用户暂时选择讲解时，完成当前讲解并保留实践入口。
- Agent 可以承担检索、计算、制表、编码和内容整理；用户决定参与程度。实践结果需要继续写成教程、文章、复盘或平台正文时，本阶段先交付可观察结果、过程、依据和边界，再由上层进入已经选定的写作类型与平台阶段。

### 普通人行动总结与正式依据分开

技术知识转成现实应用时，先给用户使用已解释普通语言即可执行或判断的行动层：观察什么、出现什么情况时怎样处理、怎样知道结果是否符合预期。

本次学习主题需要正式定义、模型、公式或成立条件时，把它们放在行动层之后的独立正式层，说明它们支撑了哪项判断。两层完整性按整份交付判断。用户明确只要单一行动产物时服从当前范围。

## 三、按知识类型选择实践

| 知识类型 | 合适实践 | 可观察结果 |
| --- | --- | --- |
| 定义 | 用它划分真实案例或边界 | 哪些属于、哪些不属于 |
| 机制 | 改变输入做情景模拟 | 原因、过程和结果怎样变化 |
| 框架 | 应用到用户案例或方案 | 哪些维度被看见，哪些仍遗漏 |
| 程序 | 在安全环境执行一次 | 步骤、反馈、错误和完成产物 |
| 争议 | 比较不同立场下的选择 | 哪个前提改变了结论 |
| 历史经验 | 对照新的事件或环境 | 哪些机制可迁移，哪些只是时代背景 |

## 四、开始前建立实践合同

正式设计前先在内部确定以下内容。简单实践可以合并展示，同时保留会改变主体结构的项目：

1. **目标产物与成功标准**：最后得到什么，达到什么状态才算满足当前用途。
2. **真实环境与可用资源**：使用用户实际拥有的材料、数据、工具、设备、能力和操作条件。
3. **时间与执行单位**：按自然日、工作周、完整循环、样本批次还是单次会话计算；先统一分母再比较频率、数量和结果。
4. **关键边界**：明确预算、权限、风险、必要假设和用户明确禁忌。
5. **输入角色与证据要求**：区分用户事实、环境约束、方法依据、事实证据、案例、推断和视觉素材。视觉素材承担展示作用；方法依据使用相应证据。复制媒体前检查许可证和署名要求。
6. **执行与观察方式**：准备采取哪些少量动作，用什么指标看到结果、差异、失败或意外。
7. **交付与沉淀位置**：结果是一次性回答还是持久化文件；写入现有项目或知识库前先读取其目录和单一来源规则，直接更新唯一正式位置。

用户已经说清时直接采用。缺失内容只影响局部表达时可以作出透明的合理假设；如果它会改变大部分产物、实际风险、验收标准或保存位置，先检查现有材料，仍无法确定时只询问该约束。

“简单易执行”描述用户需要承担的步骤和信息负担。先满足成功标准，再压缩表达、选择和操作数量。

## 五、从目标映射到执行

设计时为每项成功标准建立这条对应关系：

```text
成功标准 → 必要组成 → 可用输入或资源 → 具体动作 → 执行单位与规模 → 观察指标
```

- 同一组成缺少可用资源时，先寻找等效替代；仍有缺口时说明缺口及其影响。
- 数量、频率和比较使用统一的时间或执行单位。
- 关键方法和高影响参数使用适合其角色的证据；示例库、素材库和现成模板用于降低制作成本。
- 主流程保留执行时需要看到的内容；设置方法、动作细节、证据说明、特殊情况和复盘记录按需分层。
- 执行或演示后，用同一映射检查目标覆盖、资源匹配、指标可观察性和真实环境可用性。

实践尽量贴近用户真实用途。模拟用于降低风险，结果明确标记为模拟结果。

## 六、低压力协作

- 用共同操作、演示和选择代替闭卷回答。
- 用户卡住时提供数据、脚手架、示例或 Agent 演示。
- 提问用于获得必要约束或讨论取舍。
- 每次推进与当前产物有关的知识。
- 结果出现问题时回到对应机制补充。

## 七、根据实践结果复盘

实践出现结果后，按下面顺序整理并判断认识的稳定程度：

```text
可观察结果：实际做了什么，在什么环境、时间和执行单位下出现了什么。
候选解释：哪个机制可能产生了这个结果。
替代解释：还有哪些输入差异、测量问题、样本选择或环境变化也能解释它。
下一次验证：用新案例、反例或只改变少量关键变量的下一次实践怎样区分这些解释。
```

先用原定成功标准和观察指标判断结果。结果跨样本或跨环境重复出现、关键替代解释得到排除，或者有可靠证据补强时，把候选解释升级为稳定认识；其余保留为待验证假设或开放问题。

## 八、高风险实践

涉及金融、医疗、人身安全、法律、生产系统或不可逆外部动作时：

1. 在确定主体方案前核实会改变方法、参数或安全边界的当前规则与关键事实。
2. 优先建立纸面方案、沙盒、模拟数据或情景分析。
3. 清楚区分教育示例、分析结果和针对个人的建议。
4. 获得必要授权和用户约束后，再执行外部动作。
5. 只记录会改变结果或行动的关键假设、费用、限制和失败条件。

## 九、完成标准

实践完成表现为：

- 产生了符合用户目标与专业下限的具体产物，主流程仍然容易执行。
- 每项成功标准都能追溯到必要组成、可用资源、具体动作、执行规模和观察指标。
- 知识和证据参与了观察、判断、设计或行动，素材、案例和推断按各自角色使用。
- 会改变判断的结果、假设、时间口径和边界被记录。
- 实践复盘区分了可观察结果、候选解释、替代解释和下一次验证，并标明认识的稳定程度。
- 持久化产物位于项目规定的唯一真实位置。
- 用户可以决定停止、继续迭代或把过程转成文章与工具。
