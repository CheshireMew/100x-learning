# 单个 GitHub 项目介绍

用于在成文前保留单个 GitHub 项目介绍特有的事实边界。本文件只准备材料，文件正文、栏目和说明不进入成文输入。

完整阅读项目 README 和必要文档，先理解官方定位与能力范围。进入写作准备材料的是对本次介绍有用的项目原文，例如能够帮助读者理解项目的演示、动作、结果、场景、比较、用户反应和自然说法；理解完整能力范围不等于复制完整 README 或逐项列入所有功能。

不要把 README 机械压缩成功能摘要，也不要预先排除具体功能；一个功能确实最能帮助读者理解项目时可以成为主要内容。项目主页、安装方式、运行条件、价格、许可证、平台或提示词只在用户要求，或者会影响本次理解和行动时进入材料。完整命令参考、配置项、内部数据流、文件格式和术语说明留在来源中，只有当前介绍确实依赖它们时才选入。

普通介绍可以保留一个有用入口；安装、运行或教程请求可以使用相应命令。准备完成后只把项目原始事实和必要上下文并入材料。草稿中的实时数据和行动条件回到对应来源核对。
