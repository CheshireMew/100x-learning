# H23 原始输入开场

- 适用形式：操作演示短帖、命令教程、步骤文章。
- 适用条件：用户要求的成品本身是操作演示、教程或命令讲解，且材料有用户实际可以输入的命令、自然语言要求或明确操作，以及对应输出。
- 必须事实：`原始输入或动作`、`执行对象`、`可见输出`。
- 固定骨架：`对[执行对象]说/输入：“[原始输入]。”`
- 可选变体：命令行写 ``运行 `[真实命令]`。``
- 填写限制：照录真实可用输入；输入太长时只截取连续且仍可执行的部分。
- 禁用：用户要的是“吸引人的项目短内容”、项目介绍或宣传短帖，而不是操作演示；只因 README 恰好出现示例命令或自然语言输入就选择本模板；把功能说明改成虚构命令；示例依赖未说明参数；直接用“你只要”承诺材料没有证明的一键结果。
