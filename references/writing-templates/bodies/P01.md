# P01 输入—处理—输出

- 适用形式：操作演示短帖、Thread、教程或命令说明。
- 适用条件：用户要求的成品本身是操作演示、教程、命令讲解或具体工作流说明，且材料有真实输入、二至五个处理动作和可见输出。
- 必须事实：`输入`、`执行对象`、`处理动作`、`输出`、`一项能力证据`。
- 固定顺序：`输入（前文已经写出时不复述）→ 输出 → 中间动作 → 能力证据`。
- 逐段骨架：前文没有输入时才照录用户输入或动作；再写输出；随后按发生顺序列二至五个自动动作；最后只放一个数字、格式、模型或结果证据。
- 长度：短帖每步一句；Thread 每步最多一条；长文可把关键步骤交给 `S01`。
- 禁用：用户要的是“吸引人的项目短内容”、项目介绍或宣传短帖，而不是操作演示；只因 README 有一条输入输出示例就选择本模板；重复钩子或承接已经写出的输入、结果或利益；从痛点开场；把全部功能塞进中间动作；“提升效率”式升华；安装条件混进正文。
