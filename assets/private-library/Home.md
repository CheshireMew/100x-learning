# 私人知识库

这里保存只属于当前用户、会跨任务继续使用的知识、来源、项目、成果和写作研究语料。它与 100x-learning 的可发布 Skill 源码分开；任何能够读取本地文件的 Agent 都可以按本页约定使用，不依赖某个客户端的专属目录。

## 目录边界

| 目录 | 放什么 |
| --- | --- |
| `00-Inbox` | 暂时无法判断归属、仍待复核的材料 |
| `10-Knowledge` | 已经消化、可以反复使用的概念、结论、机制和方法 |
| `20-Sources` | 外部文章、书籍、课程、字幕、访谈、原帖和其它原始材料 |
| `30-Projects` | 有明确目标、交付物和结束条件的进行中工作 |
| `40-Outputs` | 已经确认完成的文章、研究稿和其它成果 |
| `50-Areas` | 没有固定结束日期、需要长期维护的领域 |
| `60-Systems` | 可重复使用的流程、模板、写作声音和工作规则 |
| `90-Archive` | 已结束或停用但仍需保留的内容 |

原始材料进入 `20-Sources`，从材料形成的稳定认识进入 `10-Knowledge`。知识文档链接来源；完整案例与独立钩子按不同的用户保存动作进入各自真源，二者不互相派生或引用。

## 内容案例与钩子

- 完整社交内容保存在 `20-Sources/Social Posts/Content Cases/完整社交内容`，独立短帖与 Thread 不再分开。
- 独立钩子保存在 `20-Sources/Hook Library/Examples/<写作技巧>`，只保存原始开头、紧接内容和最少定位字段，不附加来源，也不区分短内容、Thread 或文章。
- 正式文章保存在 `20-Sources/Articles` 的其它目录；文章案例是复制到 `20-Sources/Articles/Content Cases` 的独立无来源副本，不能与正式文章共用同一文件。
- 完整案例分别使用 `20-Sources/Content Cases/社交内容案例索引.md` 与 `文章案例索引.md`；所有钩子共用 `20-Sources/Hook Library/钩子索引.md`。所有索引只按可迁移的写作技巧分组，不按题材、对象、行业、任务或成品形式检索。

完整案例保存从第一句到最后一句的原文和必要定位字段，不附加来源；活动文件与索引条目使用不带题材含义的稳定编号，标题只在打开原文后出现。钩子保存经用户明确指定的一段连续原始开头、紧接内容和最少定位字段，同样使用稳定编号且不附加来源；案例导入不会自动建立钩子。

案例和钩子只在明确的语料维护或模板蒸馏任务中读取。普通写作使用 Skill 源码中的完整写作模板，不直接读取这些原文，也不让多个案例或钩子共同决定一篇成品。

## 面向人和 Agent 的知识文档约定

新建或实质更新 `10-Knowledge` 中的主题文档时使用：

```yaml
---
type: knowledge-note
status: active
created: YYYY-MM-DD
updated: YYYY-MM-DD
topic: 稳定且唯一的主题标识
aliases:
  - 真实存在的别名、缩写或英文术语
---
```

文件名和唯一的一级标题直接说明主题。标题后先说明文档回答什么问题、当前结论和适用范围，再保存机制、证据关系、限制、冲突和开放问题。重要来源链接放在它支持、限制或反驳的主张附近。

写入前先搜索主题、别名和来源。处理同一个问题时更新现有文档；新材料只是证据、案例或限制时合并到对应位置；只有能够独立回答另一个长期问题时才新建主题。

## 写作记忆

确认稿和已发布成果保存在 `40-Outputs/Writing`。发布历史索引、写作记忆配置和长期声音位于 `60-Systems/Writing`。发布历史、声音资格和内容案例承担不同用途，不能从发布状态或案例身份推断作者声音。

## 写入与归档

普通理解、研究和写作只在当前回复中交付。用户明确要求保存、沉淀、更新、加入案例库或加入钩子库时才写入。写入后重新读取实际文件并运行对应索引验证，告诉用户更新了哪些真源。

活动内容有新结论时更新原文件。已经停用的内容移入 `90-Archive`；归档不是删除，也不在活动目录保留兼容副本。
