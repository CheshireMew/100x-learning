# Claude-Mem 让 Claude 拥有跨会话记忆

## 原帖全文

这个人刚刚解决了 Claude Code 的最大痛点。

这个项目叫做 Claude-Mem，它让 Claude 具备了跨会话的持久记忆能力。

• 每次最多可节省 95% 的 Token 消耗。
• 在达到使用上限前，工具调用次数可提升 20 倍。

100% 完全开源。
