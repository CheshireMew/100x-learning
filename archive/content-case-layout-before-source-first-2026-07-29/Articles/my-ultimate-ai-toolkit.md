# 从 0 开始用 AI：我的日常工具清单

我猜有很多小伙伴一直想学习 AI，但是不知道用什么，因此迟迟没有行动。

在这篇文章中我会介绍自己日常高频使用的 AI 工具，希望能帮助大家快速行动，早日接触 AI 的美妙之处。

首先我要强调一点，AI 最大的创新就是能让普通人用自然语言跟它交互。

所以使用 AI 不要有什么负担，跟它直接说你的需求就完事了。可以说是最好入门的东西，没有之一！

#### [1. Gemini](https://gemini.google.com/)

我自己最常用的 AI 是网页版的 Gemini，Pro 会员也是之前学生优惠白嫖的。

Gemini 最大的特点是上下文长度很长，因此如果你需要整理一些繁杂的资料可以交给它。

虽然现在有点降智，但至少也是排行老三的那个。

并且它不会像 GPT 那样吐出来的字都是浓浓的 AI 味，你可以把写作之类的任务交给它。

虽然因为智商的原因写不出什么惊艳的文章，但至少够用了。

平时问问问题、做做简单任务啥的，都是可以胜任的。

另外，推荐一个比较好用的 Gemini 插件，可以有效管理提示词和对话记录：[gemini-voyager](https://github.com/Nagi-ovo/gemini-voyager)

![image](https://blog.blacknico.com/wp-content/uploads/2026/07/image-19-1024x576.png "从 0 开始用 AI：我的日常工具清单")

#### [2. ChatGPT](https://chatgpt.com/)

GPT 应该是比 Gemini 聪明一点的，像生活建议、心理健康、人生哲学、健康问题等内容应该问 GPT，不会像 Gemini 那样迎合你并且乱答。

我的失眠就是被 GPT 找到根因并治好的，详情见：[这样下去我绝对会死](https://blog.blacknico.com/think/this-is-going-to-kill-me-if-it-keeps-going/)。

总之天不生 GPT，医道万古如长夜啊！

另外，现在 GPT 的 image2 生图吊打 Gemini 的 Nano banana Pro 了，所以生图必用 GPT！

但 GPT 的语料库大概是被污染了，特别喜欢用诗歌体。

什么是诗歌体？如图所示：

![image](https://blog.blacknico.com/wp-content/uploads/2026/07/image-20-896x1024.png "从 0 开始用 AI：我的日常工具清单")

无论你用什么样的去 AI 味提示词，GPT 永远都是我行我素。

因此在写作这方面，我给 0 分。

#### 3. Codex

Codex 和 ChatGPT 都是 OpenAI 一家出的，Codex 是一个 AI 编程工具，虽然可能大家没有编程需求，但你可以有！

而且如果你想整理文档 / 资料、自动化某些流程，Codex 可比其它工具强大太多了。

只要能在电脑上干的，它都能帮你代劳。

你电脑上必须要有个 Codex 好吧。

我之前写过一篇 Codex 的入门教程，感兴趣的可以收藏看一下：

[量大管饱 AI 编程新秀 Codex 简明教程](https://blog.blacknico.com/guide/codex-quick-start-the-heavyweight-ai-coding-rookie/)

#### 4. Grok

在我看来，Grok 算是行业老四吧。

如果你订阅了 X 会员的话，Grok 不能浪费，必须要时常用一用。

因为有 X 在背后做官方支持，搜索 / 抓取推文或者新闻热点也是轻轻松松，做做简单的任务也不在话下。

但要说最厉害的还是 grok 的生成视频功能，做一下小动作幅度的视频可以说是效果非常棒，我觉得仅次于 Seedance。

最近视频长度甚至还延长到了 15s。

![image](https://blog.blacknico.com/wp-content/uploads/2026/07/image-21-1024x687.png "从 0 开始用 AI：我的日常工具清单")

不过生图功能就别指望了，非常的丑陋。

马斯克也推出了自家的 AI 编程工具 Grok Build，原本的使用效果就已经很不错了，最近还收购了 Cursor 推出了新模型，效果应该更棒了。

这是我之前写过的教程：

[你的 X Premium+ 订阅赚翻了：Grok Build 安装与实战全攻略](https://blog.blacknico.com/ai/your-x-premium-subscription-just-paid-off-big-time-the-ultimate-grok-build-installation-and-hands-on-guide/)

#### 5. 豆包

如果要我推荐一个国产 AI，那豆包还是有一席之地的。

除了能免费生成图片和视频外，豆包其实还能帮你找资源。嗯嗯，当然“看图找番”那种程度是别想了，会被和谐的。
