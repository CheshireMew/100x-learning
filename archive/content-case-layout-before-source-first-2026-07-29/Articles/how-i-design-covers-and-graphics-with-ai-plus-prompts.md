# 我是如何用 AI 设计封面和说明图的（附提示词）

有了 IP 形象后，我现在所有的图片都是 AI 生成的，无论是现在这篇文章的封面，介绍项目的说明图，还是文章内的插图，都可以代劳。

**最近我发现了一个新的理论：所谓的传播，就是精神污染。**

你的形象只要在人们视野中出现 100 遍，他们就会记住你。

所以只要有机会，我就会疯狂地使用自己这个 IP 形象，毕竟亲生的，还那么可爱。

#### 1. 封面图

我最近已经立誓要每天写一篇文章，因此封面图必不可少，这是我打磨出来的一套生成封面的提示词，你可以直接拿去使用：

```
请根据下面文章的内容和上传的图片生成一张 5:2 二次元可爱风的封面图，整体要有张力和吸引力！封面文字必须少而有力，不要出现过多杂乱文字。要清晰有设计感，如果有文字除了专有名词外用中文！这张封面的目标不是复述文章全部内容，而是提炼文章中最有传播力、最能激发点击欲的核心情绪和核心冲突。画面要一眼能看懂主题，有清晰主次，不要信息堆砌，不要像文章摘要图。上传的图片说明：第一张是该品牌的 LOGO 和色调，第二张是我个人的 IP 形象图，人物可以根据内容调整动作、情绪、服装、神态等，不要死板，请将它们融入封面中。下面是文章内容：
```

后面接上整篇文章的内容就行，标题可以给也可以不给，看情况。有些时候给了标题 GPT 会直接拿标题当成封面的文字，需要强调的时候这样是非常好的，但是要互补信息时反而不美，这时候就可以不给。

另一个缺点是 AI 会使劲往图里塞文字，整得比说明图还夸张，你可以观察一下其他人生成的封面是不是这样？没有层次。

我这个提示词已经很大程度上避免了这个问题。

![Image](https://blog.blacknico.com/wp-content/uploads/2026/06/Image-77-1024x409.png "我是如何用 AI 设计封面和说明图的（附提示词）")

#### 3. 文章插图

最近很流行那个小黑形象的插图 skill，确实不错，但那毕竟是人家的形象，咱们可以用自己的！

**直接复制下面的提示词：**

```
请根据我上传的 IP 形象，为下面的内容生成一张简洁横版插图。画面比例 16:9，适合文章配图。保留 IP 的核心特征和气质，但让角色根据文章内容自然行动。不要让角色只是站在旁边，而是让它亲自参与画面，用一个简单直观的视觉比喻，把文章里的抽象概念演示出来。画面只表达一个核心逻辑：发生了什么 → 造成什么结果。风格干净、可爱、有轻量漫画感，背景留白，主体清晰，不要信息堆砌。下面是内容：
```

不过在这之前，我们也许可以把咱们的形象简化一下，变成 Q 版，减轻观众的理解负担。

这个形象同样也可以拿来做表情包。

```
请把我上传的 IP 形象简化成适合做表情包的 Q 版人物。粗黑描边、扁平上色、低细节、颜色简洁、大头小身体、贴纸感。保留原角色最重要的识别点，包括发型、耳朵、服装轮廓、关键配饰和主色调。不要重新设计成另一个角色。表情要有角色性格，不要呆板。背景纯白或透明，不要文字，高清输出。
```
