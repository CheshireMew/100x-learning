# 从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）

一直都想给自己搞个 IP 形象，想得不得了，从十几岁就开始想了，但一直没有动手，因为不会画画。

但现在 AI 的绘画能力噌噌噌往上涨，最近 ChatGPT 的 image 2 绘画能力更是惊为天人，吊打 Gemini 的 Nano Banana Pro，所以我终于有机会动手了。

**今天就让我来带大家一起用 ChatGPT 打造个人 IP 形象！**

为什么要一个 IP 形象呢？

第一点，无论是谁，都想要在虚拟世界有一个数字化身来展示自我吧？让别人意识到自己的帅气、魅力亦或是美丽，这也是很多人会频繁换头像的原因。

上面这条是针对大部分人的，对于我们这种不露脸的内容博主来说，还有一个  **更真实的痛点**！

那就是，观众对你是没有印象的，即使是最经常看你内容的朋友，对你的印象也仅仅停留在头像和名字而已。

当然如果你的内容别具特色，能够让观众一眼识别，那算你厉害。

不过大部分人是做不到的，这时候有个好的 IP 形象的作用就显而易见了，不仅能够加深观众印象，还让你的内容具有个人特色，更容易被传播和识别。

**看到这里是不是有点心动？让我们开始吧！**

首先，ChatGPT 是带记忆功能的，如果你想让 AI 根据你们过去的对话来确定你的 IP 形象和性格，那记得打开“启用记忆”。

![image](https://blog.blacknico.com/wp-content/uploads/2026/06/image-49-1024x897.png "从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）")

然后打开新对话，复制下面的提示词：

```
我想为我自己设计一个二次元 IP 形象，鲜明、有特点，个性化，能代表某个有意义、有价值的符号。现在的你是一名专业的 IP 形象设计师，让我们先讨论一下如何设计？
```

记下来 GPT 会输出文字，给出具体的建议和几个选项，你可以根据自己的喜好进行挑选或修改。

![image](https://blog.blacknico.com/wp-content/uploads/2026/06/image-50-1024x871.png "从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）")

这里 GPT 根据我以前的对话，注意到了我是用的名字是 Cheshire，也就是《爱丽丝漫游仙境》里的柴郡猫，然后再结合其它的记忆给出了这些回答。

给你们看看原图是啥样的，别被吓到。

![image](https://blog.blacknico.com/wp-content/uploads/2026/06/image-51-1024x1024.png "从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）")

这样跟 GPT 对话几轮后，就可以直接让它画出来给你看看。

点文本输入框右边的加号，选择“创建图片”，图片尺寸可以选择竖版 3:4，然后复制下面的提示词：

```
根据上面讨论的结果，画一个简化版的 Q 版 3.5 头身正面视图，尽可能展示所有的细节。不要做 “ 精致设定图角色 ”，要做 “ 有强记忆点的个人 IP 角色 ”。
```

![image](https://blog.blacknico.com/wp-content/uploads/2026/06/image-52.png "从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）")

然后看看它画出来的这形象是否满意，如果超级不喜欢那就和它说 `不要绘画，我们重新讨论一下 IP 角色设定`，后面加上你不满意的点和想要的内容。

这里说一下为什么要用 Q 版简化版，因为 AI 的天然特点就是爱膨胀、爱加很多无用的细节，尤其是 image2，最后出来的图让你眼花缭乱。

**但如果问你看过之后记住了什么，那就是啥都没有。**

Q 版能一下子看出很多很问题，哪些需要哪些不需要，一目了然。

它给我的第一版是这样的，虽然很可爱，但总感觉没什么记忆点：

![image](https://blog.blacknico.com/wp-content/uploads/2026/06/image-53-819x1024.png "从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）")

当 GPT 画出你稍微满意一点的版本时，要让它给你一个 JSON 格式的生图提示词，用这个：

```
根据上面生成的图片，生成一个非常超级详细到不能再详细的中文生图 JSON 提示词，我要的是描述人物形象，不需要动作姿势和视图，也不需要描述图片尺寸。
```

这里就是 image2 的第二个坑了，你直接在原图上要求它改动，可能一开始还好，但之后会越改越偏离，效果越来越差。

你让它改胸饰，它可能改成别的东西，也可能顺手把你的鞋子改成另外一个样子。

因为 AI 不知道那到底是什么，只能通过图像识别来判断，但我们都知道人类的眼睛尚且都会欺骗大脑，何况 AI 呢？一个玻璃球，它也可能看成是珍珠。

所以我们需要一个 JSON 格式的提示词来进行约束，并且你也能从中对照 AI 和你在细节上有哪些不一致。

**刚刚说到，第一版的形象还行，但不是让我很满意，接下来该怎么修改？**

新开一个对话，把刚刚生成的图上传，然后对它说：

```
从专业的 IP 形象设计师的角度审视一下这张图
```

让 AI 自己斗 AI，让 AI 自己查 AI，你也可以在对话中给出一些建设性的意见。

我想要的是一种危险、但有吸引力的感觉，经过多轮修改后，加上了柴郡标志性的笑容后，终于对味了。

![image](https://blog.blacknico.com/wp-content/uploads/2026/06/image-54-819x1024.png "从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）")

但等等，这个色调不太对，很难看。

这就是 image2 的第三个坑了，无论你怎么要求修改，它都会沿用原来的姿势和色彩，并且会越来越偏离，所以你要和它说：

```
请完全重新设计配色方案！给我几个不同的方向。
```

接下来就是 ChatGPT 中一个非常好用的功能了，你可以为每个方案创建一个聊天分支，让它都画出来给你看看。

![image](https://blog.blacknico.com/wp-content/uploads/2026/06/image-55-900x1024.png "从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）")

只要是遇到不同方案的情况都可以用，并且减少了不同方案在同一个对话中污染上下文的可能性。

在 JSON 提示词和图片的约束下，人物一致性算是确立起来了，也算是完成了一个小目标。

如果你想继续敲定细节，可以和 GPT 继续探讨，将更多的细节加入 JSON 内容里。

在敲定更多细节的过程中，你可能会遇到 AI 画出来的死活都不是你想要的情况，比如这个小女孩身上的小斗篷，AI 画着画着就变成了别的衣服。

这时候我就让它作为一个专业的服装设计师，解剖一下：

```
你现在是一名专业的服装设计师，请你根据上面 JSON 中的关于斗篷的描述词画出它的专业设计图
```

![image](https://blog.blacknico.com/wp-content/uploads/2026/06/image-56-1024x571.png "从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）")

三视图也是稍微有点重要，但又不是那么重要，说它重要是 AI 还不是知道角色背面是什么样子，你可以把三视图给它看让它在 JSON 中添加更多背面和侧面的细节。

比如说我这个小斗篷背面是有一块带笑脸的装饰背片的，只看正面根本看不出来。

![Image](https://blog.blacknico.com/wp-content/uploads/2026/06/Image-57-1024x576.png "从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）")

画三视图的提示词如下：

```
参考图片角色，制作它的三视图，a poss，正视图，侧视图，背视图，视图平行排开。
```

说三视图不重要，是因为你生图的时候完全不能拿三视图当作参考图，会污染上下文，即使你想生成的图片里的人物是正面站着，AI 也会把背面的元素加上来，所以最好还是只给一张正面图当参考图，如果有需要可以加上 JSON 提示词。

我还做了一张人物设定集，也是同样的问题，除了自嗨一下也不能拿来生图。

![Image](https://blog.blacknico.com/wp-content/uploads/2026/06/Image-58-768x1024.png "从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）")

不管怎样，一个完整的 IP 形象总算是完成啦！接下来可以对她进行各种操作，比如扔到 grok 里生成视频、做成 Live2D 形象直播出道、生成各种狂拽炫酷的图片等等。

只有你想得到，没有你做不到。

![Image](https://blog.blacknico.com/wp-content/uploads/2026/06/Image-59-1024x576.png "从 0 开始，用 ChatGPT 打造专属个人 IP 形象（附超全提示词！）")

最后，给大家一个生成表情包的提示词，还是很好玩的：

```
基于我上传的角色参考图，生成一张 3 行 5 列（共 15 格）的动漫角色表情包网格图。核心约束（必须严格遵守）：角色绝对一致：所有格子中的角色必须与上传的参考图完全相同。严禁改变基础视觉特征和设计细节
风格统一：保持参考图的绘画风格
视觉风格特别要求（关键）：经典贴纸工艺感：厚实白边：每个角色周围必须有宽阔、均匀的纯白轮廓线，模拟模切贴纸的效果。轻微投影：在白边下方添加轻微的灰色投影，让角色看起来像是浮在背景上的实体贴纸，增加层次感。背景纯净：整体背景必须是纯白色，没有任何杂色或纹理。日系表情包专用字体（重点修改）：字形特征：使用标准的日系圆体或可爱的卡通手写体。笔画要粗细均匀、圆润饱满，不要有复杂的立体阴影、高光或渐变效果。文字要是扁平化的。描边处理：文字必须有清晰的黑色或深色外描边，以保证在任何背景下都清晰可读。色彩填充：文字内部填充高饱和度的纯色（如亮粉、天蓝、明黄），颜色要实，不要花哨的纹理。排版位置：文字通常位于角色的头顶、侧边或底部，大小适中，不要遮挡角色的脸部。具体画面内容规划（从左到右，从上到下）：第一行（日常互动）：打招呼：角色微笑，旁边配粉色粗圆体 “ 嗨~！”。点赞：自信表情，配橙色粗圆体 “ 拿捏了 ”。逃跑：角色做出快速奔跑的动态模糊姿势，配蓝色速度线字体 “ 溜了溜了 ”。看手机：角色低头看手机，流汗尴尬表情，配小气泡。展示：角色整理羽毛，配竖排棕色圆体 “ 今份穿搭 ”。第二行（情绪表达）：抱怨：角色看着手机皱眉，配白色气泡框 + 黑色文字 “ 网速好慢...”。魔法：角色双手张开做施法动作，周围有星星特效，配紫色粗圆体 “ 变身魔法！”。全身像：角色自然站立半身像，配竖排棕色圆体 “ 今日份穿搭 ”。疑惑：角色满头问号震惊脸，头顶红色大问号，配文字 “？”。不屑：角色托腮斜眼看人（鄙视脸），配黑色粗体 “ 就这？”。第三行（夸张反应）：崩溃：角色夸张大哭流泪（瀑布泪），配蓝色裂纹字体 “ 我裂了 ”。震惊：角色极度震惊疑惑脸，配红色粗体 “ 哈？？”。贴贴：角色蹭蹭，配粉色粗圆体 “ 贴贴~ 贴贴~”。疲惫：角色灵魂出窍疲惫状，旁边有幽灵图标，配蓝色圆体 “ 累了...”。比心：角色双眼冒星星，周围有粉色爱心，配竖排粉色圆体 “ 绝绝子！爱你是我更是 ”。
```

参考它先用自己多年想做却不会画画的经历解释教程为何出现，再让读者跟着一次真实创作逐步推进。每当结果跑偏，就当场解释原因、调整提示词并展示新版，而不是只给一套理想步骤。

## 适用场景

适合创作类、设计类或需要多轮反馈的 AI 教程。重点参考“结果—判断—调整”的过程，不要僵硬复制提示词。
