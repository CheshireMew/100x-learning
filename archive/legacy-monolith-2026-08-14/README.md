# 旧单体入口

这里保留 2026-08-14 拆分前的根级 `100x-learning` 入口和界面元数据，仅用于追溯原有行为，不再参与 Skill 发现或正常运行。旧入口特意命名为 `SKILL.legacy.md`，避免 Codex 把历史快照识别成第二个同名活动 Skill。

原有能力已经迁移到三个活动入口：

- `skills/100x-learning`：材料理解、研究、概念解释、实践和长材料项目；
- `skills/private-knowledge`：私人知识库初始化、接入、沉淀、检查和 Marktree 协作；
- `skills/content-system`：分享筛选、内容策略、选题、发布复盘、案例、钩子和写作记忆。

原有可发布文字能力由已经存在的 `prep-this`、`write-this` 和 `clean-copy` 承接。迁移过程没有删除旧说明；不应从本目录恢复第二套活动入口。
